## Purpose
I wanted a tool to address a weakness I (and many others) have when playing mahjong in person after mostly playing online clients: keeping score.

There are other apps out there, but none of them are perfect for me. The downside is it's cumbersome to key in 14 tiles, plus all the context needed (riichi? seat wind? under the river? robbing a kan? etc.) to make sure it gets all the han right. The problem compounds if you don't play in person very often (and compounds further when beers are involved), and you have to relearn how to drive the interface every time you open the app.

This aims to be an intermediate-level tool; you already know the yaku in your hand, and you have tenbou sticks (or another means) to track each player's score, you **just need to count fu**.

I wanted it to be agnostic of the exact tiles, and just focus on the few properties of each group that actually determine fu score. Showing the intermediate values is important to demystify the black box, and hopefully teach the pattern instead of just spitting out a number. It's also important that while the number of inputs is minimal, all relevant options are out in the open, to act almost like a checklist to learn from & internalize.

### Alternatives (for Android devices)
Mahjong Helper by Cyberdog Software is an excellent tool. It scores individual hands, and also tracks the game round by round. Very powerful, and fun if you like to keep a log of games played with IRL friends.

If all you need is a single-hand score, Riichi Calc is good too. The "tile keyboard" input is nice, but I really don't like that the vital "conditions" entry is hidden offscreen until you swipe the whitespace (and the only indication that it exists is covered up by a banner ad).
